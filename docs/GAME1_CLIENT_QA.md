# Client layout and controller audit

Date: 2026-10-26. This batch is offline validation of client changes. It does not certify mobile rendering or gamepad input.

## Concrete corrections

- Portrait touch controls stack on the right above the jump area, avoiding the left thumbstick region. Landscape retains separated right-side action buttons. Compact landscape canvases below 330 usable pixels high use a shorter row beneath the HUD. The bank guide moves away from bottom touch controls.
- Layout uses the ScreenGui's usable `AbsoluteSize`, with the camera viewport as an initialization fallback. Roblox documents actual GUI pixel size in [GuiBase2d.AbsoluteSize](https://create.roblox.com/docs/reference/engine/classes/GuiBase2d); actual safe-area reporting still needs device verification.
- Panel title, tab text and objective scale within explicit font bounds. This addresses clipping identified from their fixed widths; it is not a substitute for font rendering review.
- Controller menu entry selects the active tab. Tabs have explicit horizontal navigation and downward access to the first action, or the album scroll area. Results focus the replay button. Row refreshes preserve the selected action by stable row/button name. Returning to play clears result focus.
- Collection uses M or controller Select. Keyboard typing does not toggle the collection. Default player-list display is disabled with bounded initialization retries because it overlaps the score HUD.
- Stable QA object paths remain unchanged from the naming batch. Collection child rows use `Album_<speciesId>`, `Upgrade_<key>`, `Quest_<questId>`, `Arena_<biomeId>`, and `Setting_<key>`.
- Client results contain no unconditional "safe" or "saved" claim. The save indicator displays the server-provided `saveStatus`; currency earned is distinct from durable save confirmation.

## Reproducible checks

Windows PowerShell and official Luau CLI 0.744:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tests/SparkClientLayoutSmoke.ps1
.tools/luau/luau-compile.exe --null game/StarterPlayer/StarterPlayerScripts/Spark/Client.client.luau
```

Both final commands exited 0. The layout harness extracts the actual pure `layoutFor` function from Client, so it evaluates current layout calculations rather than a separately maintained copy. Output:

```text
PASS pure client layout: 11 usable-canvas cases, 181 geometric assertions
NOT TESTED: Roblox rendering, font measurement, actual CoreGui bounds, touch input, gamepad focus or safe-area reporting
```

Usable-canvas cases: touch 320×480, 320×532, 360×604, 390×808, 568×284, 667×339, 844×354, 1024×732; non-touch 320×480, 1280×684, 1920×1044. Dimensions describe usable UI canvases, not claimed device/emulator observations. Assertions check element bounds, action-button separation, and touch action/bank separation from objective, collection and conservative reserved thumbstick/jump rectangles.

The initial test failed at touch 568×284: Catch overlapped the objective. Adding the compact landscape row corrected the measured geometry failure. The rerun passed all cases. No device screenshot or controller-action evidence is generated by this test.
