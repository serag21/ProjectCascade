## 2. Reproducible setup and checks

Prerequisites: Python 3.10+ and the official Luau 0.744 CLI in `.tools/luau/` (`luau`, `luau-compile`, `luau-analyze`; on Linux also symlink `luau.exe` → `luau`). Download the release zip for your platform from github.com/luau-lang/luau/releases/tag/0.744. The Roblox API dump for the API-name checks goes at `.tools/api/Full-API-Dump.json`.

Run the full offline suite (writes `docs/qa/latest-checks.json`; fails closed if any source changes during the run):
```bash
python3 tools/run_checks.py
```
Verify the audio files and manifest:
```bash
python3 tools/generate_audio.py --verify
```
Re-render all audio and confirm byte-identical output:
```bash
python3 tools/generate_audio.py --reproduce
```
Print the economy model table and run its bounds:
```bash
.tools/luau/luau tests/SparkEconomy.spec.luau
```
Run one headless scenario (for example, the Daily Stampede):
```bash
python3 tests/test_spark_headless.py --scenario ScenarioJ
```

## 3. Build and install into Studio (Edit mode)

Generate the installer:
```bash
python3 tools/build_studio_install.py
```
This writes `build/install-spark.luau` and `build/spark-manifest.json` (gitignored). Paste the installer into the Studio Command Bar in **Edit** mode on Project Cascade [DEV]. It preflights, writes, reads back every source by SHA256 and rolls back on any failure. Full procedure: `docs/GAME1_PLAYTEST_GUIDE.md` §1.

After uploading the WAVs in Studio (Asset Manager), set their IDs. Preview first:
```bash
python3 tools/set_audio_ids.py --dry-run ids.json
```
Then write them:
```bash
python3 tools/set_audio_ids.py ids.json
```
