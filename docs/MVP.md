# MVP Specification

## Player-facing mission

**Activate the observation array and transmit a recovery signal.**

## First playable chain

Spawn → restore power → opened route → reach array → activate array → environmental transformation → transmit signal → final cascade → escape.

## First playable systems

- Power
- Access/doors
- Environment state
- Lighting state
- Objective state
- Security/cascade state
- Event notifications

## Multiplayer constraints

- A single player can finish the run.
- Additional players create parallel opportunities and faster discovery.
- No required voice communication.
- No hard dependency that can strand the remaining team.
- Important progress is broadcast visually to everyone.

## Explicitly out of MVP

- Inventory system
- Economy/currency
- Crafting
- Pets
- Large progression trees
- Multiple maps
- Combat roster
- Full procedural map generation
- Monetization
