# Updated Build Plan

## Immediate target: a convincing playable vertical slice
- Enclosed low-light research facility with a readable multi-room layout and optional side discovery.
- A causal sequence: power → machinery → drainage → route change → observation array → containment release → chase → transmit → escape.
- Connected route and gate geometry; no interaction should be a nonfunctional decorative button.
- Ambient/positional audio, machinery onset, door movement, alarm, growls/footsteps, distant impacts and threat proximity feedback.
- Broad persistent mission UI plus short event feedback; avoid step-by-step chore lists.
- Test script sync reliably and fix any source/runtime errors.

## Next iteration after playtest
- Review pathfinding failures, creature speed/damage, and whether the chase creates tension without becoming unfair.
- Replace placeholder/procedural props with coherent authored assets where they improve readability/atmosphere.
- Refine audio timings, quieter exploration vs alarm/chase mix, light flicker, room ambience and transformation choreography.
- Add a second consequence choice only after this first causal chain works and is interesting.

## Shipping schedule guardrails
Day 45 is the target; Day 60 is the ceiling. Build only what helps prove the core loop. No economy, crafting, pets, extensive progression trees, multiple maps or monetization before the game is fun.
