# 45-Day Build Plan

## Days 1–3
- Publish private development experience.
- Connect Script Sync.
- Run the generated facility.
- Verify objective/event HUD.
- Verify one cause/effect interaction.

## Days 4–10
- Polish the first power → door → array chain.
- Add first environmental transformation.
- Add solo completion and run reset.
- Smoke-test 1–4 players.

## Days 11–17
- Add a second consequence path.
- Improve lighting/audio/visual feedback.
- Test with friends.
- Cut anything confusing or boring.

## Days 18–28
- Add 2–3 controlled run configurations.
- Add one or two useful optional tools/discoveries.
- Add automated state tests and begin headless execution.

## Days 29–38
- UX and accessibility pass.
- Controller/mobile pass.
- Lighting/audio polish.
- Performance pass.
- Public-alpha testing.

## Days 39–45
- Bugs and usability fixes.
- Thumbnail/icon/store copy.
- Final friend testing.
- Publish.

Day 45 is the target. Day 60 is the hard ceiling.
