# Project Cascade

Project Cascade is a 1–4 player cooperative environmental adventure for Roblox.

## Core loop

Explore → interact → cause change → observe consequence → adapt → accomplish objective → survive the final cascade → escape.

## MVP

The first playable slice is a compact research/observation facility:

1. Restore power.
2. Reach and activate the observation array.
3. Experience a controlled environmental transformation.
4. Transmit the recovery signal.
5. Escape during the final cascade.

### Design pillars

- Co-op amplifies fun; it never gates it.
- Solo-completable and viable with silent/random teammates.
- Stable landmarks, unstable circumstances.
- Player actions cause visible environmental changes.
- Important changes are visually/audibly telegraphed.
- Every player should have something meaningful to do.
- The first 60 seconds should demonstrate the core fantasy.
- No random disappearance of important objectives.
- MVP scope is aggressively protected around the 30–45 day shipping experiment.

## Repository layout

`src/` mirrors the Roblox DataModel locations used by Script Sync.

`tests/` contains framework-light state tests suitable for future headless Luau execution.

The initial world geometry is generated by Luau so we can iterate quickly without hand-building the entire facility before the first playtest.
